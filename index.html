BroBot Overlay

Privacy Policy

Experimental version 0.1.0 · Last updated: 29 October 2026

Purpose

BroBot Overlay is a parent-supervised educational browser extension that places a compact lesson helper and prepared question hints over a webpage when the user clicks the extension button. It requires a separate BroBot server operating on the family's local network. It does not automatically read or control the visited teacher website.

Information used and stored

  • Lesson selection: The extension keeps the selected lesson identifier and manually selected slide number in Chrome's extension session storage to maintain the overlay across tabs during the browser session.
  • Hint requests and progress: When a user requests a hint, the extension sends the lesson identifier and question identifier to the family's local BroBot server. The server returns the prepared hint and maintains the per-question hint counter according to the parent-controlled BroBot application. These actions constitute limited use/activity data necessary for the extension to work.
  • Local-network address: In handling requests, the BroBot server receives the connecting device's local IP address and prints the local IP address and request path to its local server log. The extension does not use the address to determine geographic location.
  • Lesson text: The extension retrieves parent-prepared lesson labels, slide metadata, questions and hint text from the local BroBot server for display; it does not upload that information to a third-party service.

The extension does not extract, record, or transmit the text, images, forms, schoolwork, browsing history, page addresses, or keystrokes from the teacher website where the overlay is shown. It does not collect account passwords, payment details, health records, or messages from that website.

Network and security

The experimental version communicates with a fixed private-network BroBot server using HTTP, not HTTPS. Traffic on that local network is therefore not encrypted in transit. The extension is intended only for use on a trusted private network while this limitation is being addressed. Do not use it across public or untrusted networks. The local BroBot server restricts access to its allowed subnet and only exposes child-facing lesson and hint functions to the extension; it does not grant access to parent credentials or parent controls.

Sharing and use

The extension does not send collected data to advertising networks, analytics services, data brokers, or a developer-operated internet server. Lesson selection, hint requests and related progress are exchanged only with the family's local BroBot server to deliver the selected learning assistance. No data is sold. Data is not used for advertising, creditworthiness, or purposes unrelated to the extension's educational function.

Retention and controls

The extension's selected lesson and slide data are stored in Chrome session storage and are not intended as long-term account history. The family's BroBot installation controls its own hint progress and parent-reset workflow. The parent can manage lesson availability and hint progress using the local BroBot application. Local server console logs may be retained if the computer owner captures them; the extension does not upload or centrally retain those logs.

Children's use

The extension is designed for parent-supervised use. A parent controls the local BroBot server and prepares lesson content. The extension itself does not provide unrestricted AI conversation, parent administration, or independent web searches.

Contact

For privacy questions, parent support, or BroBot Overlay extension enquiries, contact brobotsupport@gmail.com.

Please do not include children's names, student records, lesson materials, passwords, or other sensitive information in an initial support email.

This policy will be updated if BroBot's network transport, permissions, data handling, or sharing practices change. Use of information obtained through Chrome APIs is limited to the extension's stated educational purpose and follows the Chrome Web Store User Data Policy, including its Limited Use requirements.
